# Weather app
this a flask project that shows the current weather for any city using Openweather Api

## Features
* searching city by names
* error message for unkown cities

## How to use it 
1. the user enter a city name in the form in the homepage
1. flask receives the request and calls the open weather Api
1. index.html renders the weather data or an error if the city isnt found
